Tikkun Tool Contribute

The online tikkun for Baal Korehs

Practice with the text laid out the way a printed tikkun does: vowels and cantillation beside the plain scroll text. Free, open source, and built on Sefaria.

Three ways to read

Open source, MIT licensed

Tikkun Tool is built in the open. Fork it, fix a bug, or add a feature. Pull requests are welcome, and bug fixes are easiest to merge with a failing test that now passes.
